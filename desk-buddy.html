Setup

No wiring. One cable, one upload.

Everything is already inside the Dial. You only need a USB-C cable that carries data, Arduino IDE, and the right settings.

How it connects

Many cheap USB-C cables only charge. They have no data wires. If your computer does not see the Dial, change the cable first.

Install, step by step

  1. Install Arduino IDE 2 from arduino.cc/en/software.
  2. File → Preferences. In “Additional boards manager URLs” paste:
    https://static-cdn.m5stack.com/resource/arduino/package_m5stack_index.json
  3. Tools → Board → Boards Manager. Search M5Stack. Install it.
  4. Tools → Manage Libraries. Search M5Dial. Install it. Choose “Install all”.
  5. Make a folder called desk_buddy_dial. Put desk_buddy_dial.ino and config.h inside (see Code).
  6. Open config.h. Type your Wi-Fi name and password, and your city’s latitude/longitude for the weather. Save.
  7. Plug in the Dial. Choose the settings on the right. Press Upload (→).

If something goes wrong

No port appears

Use a data cable. Try another USB port. Unplug and plug back in.

“Library not found” error

Open Library Manager and install the library named in the error.

“Sketch too big”

Check Flash Size 8MB and the Partition Scheme above.

Time or weather is wrong

Check the Wi-Fi name and password in config.h. Use 2.4 GHz Wi-Fi.

Upload fails half-way

Unplug, plug in again, upload again. If it still fails, put the Dial in download mode (see M5Stack’s M5Dial docs).

Volume knob not in Bluetooth list

Open Mode 3 first. Then search for “Desk Buddy” on your PC or phone.

What stays the same

  • Chassis, 4 TT motors and wheels
  • L298N motor driver, ENA/ENB jumper caps still off
  • Motor wires on OUT1–OUT4
  • 2 × 18650 battery box, switch, battery wires
  • HC-SR04 Eyes on the MG90S servo Neck

What is new

  • ESP32 DevKit instead of the Arduino Uno
  • New pin numbers (25, 26, 27, 16, 17, 33, 18, 19, 23)
  • Two resistors for the Echo wire (1 kΩ + 2 kΩ)
  • L298N 5V → ESP32 VIN, and a common ground
  • New sketch: smart_car_esp32.ino

Part 2 · Wiring

ESP32 car: every connection

Same wire colours as Part 1. Red is + power, black is GND. Pin numbers are the GPIO numbers printed on the ESP32 board (D25 = GPIO 25).

Echo needs the divider. The HC-SR04 Echo pin gives 5 V. The ESP32 pins take 3.3 V. Without the 1 kΩ + 2 kΩ divider, the 5 V echo can damage the ESP32.

Wiring diagram

Swipe sideways to see the whole diagram.

Every ⏚ symbol is GND, and all GNDs are joined: battery −, L298N GND and ESP32 GND.

Pin table

Check each wire with your finger, one row at a time.

FromToWireWhy
Never power the ESP32 from USB and from the L298N 5V at the same time without the common ground. Simplest: unplug the USB before you switch the battery on, or keep the wheels in the air while you test on USB.
Part 2 · Code · smart_car_esp32.ino

The car sketch

One file for the ESP32 on the car. The Dial side is the Remote mode that is already in desk_buddy_dial.ino.

Upload it

  1. Boards Manager: install esp32 by Espressif Systems, version 3.x.
  2. Make a folder smart_car_esp32 and put smart_car_esp32.ino inside.
  3. Battery switch OFF. USB cable to the ESP32.
  4. Tools → Board: ESP32 Dev Module. Pick the port. Upload.
  5. Upload fails? Set Upload Speed to 115200, or hold BOOT while it says “Connecting…”.
  6. Serial Monitor at 115200: it prints “searching ch …” until it hears the Dial.

Settings you may change

At the top of the sketch (and one in the Dial’s config.h).

LEFT_REVERSED
RIGHT_REVERSED		Flip true/false if one side spins backwards in the wheels-in-the-air test. Left starts as true, like Part 1.
SERVO_CENTER90 = Eyes straight. Crooked? Try 85 or 95.
AUTO_WHEN_ALONEfalse = wait for the Dial. true = drive by itself and avoid obstacles (like Part 1) when no Dial is heard.
STOP_CM / SLOW_CMBrake below 22 cm, slow below 45 cm.
REMOTE_SPEED DialIn the Dial’s config.h. Speed in %, default 70.
KNOB_REVERSE DialIn the Dial’s config.h. Set to 1 if steering is the wrong way round.
